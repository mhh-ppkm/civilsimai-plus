## Muat naik ke GitHub Pages (sama seperti BioSimAI+)
1. Cipta repositori baharu bernama `civilsimai-plus` dalam akaun `mhh-ppkm`.
2. Muat naik SEMUA fail dalam folder ini ke akar (root) repositori:
   `index.html`, `manifest.webmanifest`, `sw.js`, `icon-180.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. Buka https://mhh-ppkm.github.io/civilsimai-plus/ dalam Chrome (Android) atau Safari (iPhone), tekan **Pasang aplikasi**.
5. Selepas dibuka sekali dengan internet, semua tab berfungsi tanpa talian.

Jika anda mengemas kini index.html kemudian, tukar `CACHE='civilsimai-plus-v1'` dalam sw.js kepada `v2` supaya telefon pelajar menerima versi baharu.
